# ecom-analysis
Проект, выполнен в рамках обучения на Специализации Яндекс Лицея - "Анализ Данных"


## Цель проекта и задачи
### Цель: 
> Выяснить, в какой регион и какой рекламный канал инвестировать больше денег на привлечение клиентов в следующем году (с обоснованием своего предложения)

### Задачи
- Провести разведочный анализ данных (EDA) и предобработку данных;
- Изучить распределения ключевых показателей;
- Выявить особенности и аномалии в данных;
- Сформулировать и проверить гипотезы;
- Отобрать признаки по значимости;
- Построить регрессионную модель для предсказания продаж;
- Создать дашборд, включающий основные метрики;
- Сформулировать рекомендации для бизнеса.

## Запуск ячеек кода в data_analysis/
1. Клонирование репозитория
``` bash
git clone git@github.com:frlsua/ecom-analysis.git
```

2. Переход в папку data_analysis
``` bash
cd data_analysis
```

3. Создание виртуального окружения (MacOS), его активация и скачивание необходимых библиотек
``` bash
python3 -m venv venv
```

``` bash
source venv/bin/activate
```

``` bash
pip install -r requirements.txt
```

4. Настройка переменных окружения в .env (пример находится в .env.example)


## Итоги
1. Очистка датасета с максимальным сохранением данных: $1012 \rightarrow 1002$
2. Выявлены регион и канал с наибольшим потенциалом для инвестиций;
3. Около 1,1% уникальных пользователей делают повторную покупку, следовательно, необходимо обратить внимание на способы удержания клиентов;
4. Для линейной регрессии $R^2 = 0$, следовательно, для прогнозирования продаж стоит попробовать более сложную модель, например, логистическая регрессия для предсказания, будет ли совершена покупка, и ансамбль деревьев - для суммы покупки.
